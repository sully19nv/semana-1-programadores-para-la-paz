Al ejecutar el comando node server.js, el servidor inicia correctamente y queda escuchando solicitudes en el puerto 3000.

El mensaje que aparece en la terminal es:
"Servidor ejecutándose en puerto 3000".

Al visitar la ruta /estado en el navegador, el servidor responde con información en formato JSON indicando que el servidor está funcionando y que el servicio corresponde a una API comunitaria.

Respuesta obtenida:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
